# Human-Written Code Declaration

This project was developed manually by the project team. The application source, configuration, APIs, database schemas, tests, frontend components, styles, deployment configuration and documentation were authored directly by the team and are not copied, adapted or generated from AI output.

The team may use official documentation and learning resources to understand APIs and technologies, but no generated code from an AI system is incorporated into the project. The project owner is responsible for reviewing and accepting any future third-party code and ensuring that its licensing and provenance are compatible with this declaration.

## Verification checklist

- Frontend React components are manually authored.
- Backend Express routes and Mongoose models are manually authored.
- Database seed data is manually authored.
- Customisation controls and product flows are manually authored.
- Tests are manually authored.
- Payment and image-storage adapters are manually authored and explicitly separated by configuration.
- Generated build artifacts in `dist/` are produced by the build tool and are not treated as source code authored by the team.
